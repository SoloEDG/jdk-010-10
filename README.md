# LUMEN 光学实验室

安装依赖：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`，生产构建：`npm run build`，测试：`npm test`。

Docker 启动：`docker compose up --build`，访问 http://localhost:18110 。

## 多层薄膜器件

在器件目录选择「多层薄膜」加入实验台，右侧检查器中可：

- 自定义**层序**（上移/下移/删除）、每层**厚度（nm）**与**材料色散**；
- 材料库含 BK7、熔融石英、MgF₂、TiO₂、Ta₂O₅、Si₃N₄、HfO₂ 等介质（Sellmeier / Cauchy 色散）
  与金、银、铝、铜（可见光 n+ik 采样表），并支持自定义 Cauchy 材料；
- 选择入射介质、基底材料与偏振（s / p / 非偏振）；
- 一键套用增透膜、V 型抗反、布拉格高反镜、金属反射膜、吸收滤光片等模板。

### 物理模型

- 膜内所有界面的多次反射以**相干**方式由 2×2 传输矩阵合成；
- 不同光源、不同波长在器件**外互不相干**，仅在功率层面叠加；
- 全程复折射率（N=n+ik）与复光学导纳，输出反射率 R、透射率 T、逐层吸收率 A，
  全反射（TIR）单独标记；
- 能量收支面板给出落到接收屏、被吸收、反射回空间、逃逸/截断的功率，并做 R+T+A=1 守恒校验，
  无源器件输出不会超过入射功率；
- 厚层自动细分为安全相位子层、反射率走导纳反向递推，上百层或极端厚度（毫米级）仍数值稳定。

### 角度 / 波长扫描

- 支持一维（波长或入射角）与二维（λ×θ 热图）扫描，分块异步执行不阻塞实时编辑；
- 扫描启动时对膜系做快照并计算指纹：扫描期间修改层序，旧报告标记「布局已变更」并保留可比较，
  不会被新曲线覆盖；
- 在曲线上选点后「应用此点」，会以**当前布局**重新计算，把波长/入射角写回光源，
  并作为一次可撤销编辑（顶部撤销/重做生效）。
